## 1. 环境与命令

```bash
pnpm install
pnpm typecheck        # 三个 workspace
pnpm test             # core 117 + vue 5
pnpm test:coverage    # 覆盖率（阈值守卫）
pnpm test:isolation   # 生产摇树隔离检查
pnpm verify           # typecheck + test + build
pnpm dev              # http://localhost:5178（/ 与 /vanilla.html）
```

- Node ≥ 22.12，pnpm 12，Vitest 5，jsdom 30。
- 自动化测试不依赖网络：网络层使用假 `fetch` / 假 `XHR`。
- 浏览器用例在 Chrome / Edge 最新版执行；Safari 16.4+ 仅做人工抽查，未纳入 CI。

### 浏览器测试的两个环境坑

1. **后台标签页的 CSS transition 会冻结**：`getBoundingClientRect` 可能拿到关闭态坐标（如 x=-399）。测量前先 `Page.bringToFront` 并等待 ≥500ms，或临时模拟 `prefers-reduced-motion`。
2. **自动化里不要用 `location.reload()`**：当前 headless harness 会把页面变成 `about:blank`；用 `Page.navigate` / `goto` 到同一 URL 等价验证持久化。

## 5. 未覆盖与风险

1. **Safari / Firefox 未自动化**：只保证 Chrome/Edge 实机；Safari 的 `backdrop-filter`、Shadow DOM 表单样式需人工抽查。
2. **真实剪贴板权限**：自动化里全部 stub；浏览器非安全上下文（http + 非 localhost）复制会走降级，需人工确认。
3. **CSP `style-src`**：未提供 nonce；严格 CSP 站点会被内联 style 拦截，接入前必须确认。
4. **多实例**：刻意不支持，未测试重复 mount 两个实例的互相干扰。
5. **极端性能**：200 条网络记录、300 条日志是硬上限；未做 1000+ 高频请求的帧率测试。
6. **可访问性**：没有 axe-core 审计，也没有完整焦点陷阱；只验证了键盘可操作与 `aria-keyshortcuts`。
7. **触屏手势**：使用 Pointer Events，未在真实 iOS/Android 上测试双指滚动与长按。
8. **iframe / Electron / 微前端**：未覆盖；Shadow DOM 宿主在 iframe 内需单独验证快捷键与层级。
