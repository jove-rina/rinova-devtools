# 05 框架接入

内核只要求 DOM。下面每种方式最终都调用同一个 `createDevtools()`。

## 1. 原生 / 任意框架

```html
<script type="module">
  import { createDevtools } from '@rinova/devtools'

  const devtools = createDevtools({
    appName: 'My App',
    enabled: true,
    theme: 'auto',
    config: [
      { key: 'apiBase', type: 'text', label: 'API 地址' }
    ]
  })

  devtools.mount()
</script>
```

完整可运行示例：`examples/playground/vanilla.html`（无框架，纯 DOM）。

## 2. Vue 3

```bash
pnpm add @rinova/devtools @rinova/devtools-vue
```

```ts
// main.ts
import { createApp } from 'vue'
import App from './App.vue'
import { createVueDevtools } from '@rinova/devtools-vue'
import { devtoolsOptions } from './devtools-options'

const app = createApp(App)
app.use(createVueDevtools(devtoolsOptions))
app.mount('#app')
```

```ts
// 任意组件
import { useDevtools } from '@rinova/devtools-vue'

const { values, isOpen, open, close, toggle, getValue, setValue } = useDevtools()

console.log(values.value.gateway) // 响应式
toggle()                          // 打开 / 关闭
open('network')                   // 直接打开网络面板
```

`useDevtools()` 返回：

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| `devtools` | `DevtoolsInstance` | 内核实例 |
| `values` | `ShallowRef<ValueMap>` | 配置值响应式快照，变化时整体替换 |
| `isOpen` | `ShallowRef<boolean>` | 面板开关 |
| `open` / `close` / `toggle` | `(pluginId?: string) => void` | 面板控制 |
| `getValue` / `setValue` | — | 透传内核 |

组件方式（不装插件）：

```vue
<RinovaDevtools :options="{ appName: 'Demo' }" />
```

组件挂载时创建实例、卸载时 `destroy()`；但它 `provide` 的是自身子树，**父组件无法 `useDevtools()`**。需要组合式函数时用插件方式。

## 3. React（v0.1 未提供独立包）

```tsx
import { useEffect, useRef, useState } from 'react'
import { createDevtools, type DevtoolsInstance, type DevtoolsOptions } from '@rinova/devtools'

export function useDevtools(options: DevtoolsOptions) {
  const ref = useRef<DevtoolsInstance>()
  const [values, setValues] = useState(options.values ?? {})

  useEffect(() => {
    const devtools = createDevtools(options)
    ref.current = devtools
    const off = devtools.on('config:change', ({ values }) => setValues(values))
    devtools.mount()
    return () => {
      off()
      devtools.destroy()
    }
  }, [])

  return { devtools: ref, values }
}
```

要点：`useEffect` 里 mount / destroy，`config:change` 写入 `useState`。后续会提供 `@rinova/devtools-react`，API 与 Vue 版对齐。

## 4. Svelte

```ts
import { onMount } from 'svelte'
import { writable } from 'svelte/store'
import { createDevtools } from '@rinova/devtools'

const values = writable({})

onMount(() => {
  const devtools = createDevtools({ appName: 'Svelte App', config })
  const off = devtools.on('config:change', ({ values: v }) => values.set(v))
  devtools.mount()
  return () => {
    off()
    devtools.destroy()
  }
})
```

## 5. 生产环境隔离

推荐按需动态导入，让 devtools 完全不进入生产 chunk：

```ts
if (import.meta.env.DEV) {
  const { createDevtools } = await import('@rinova/devtools')
  const { default: options } = await import('./devtools-options')
  createDevtools(options).mount()
}
```

或者保留依赖但关闭：

```ts
createDevtools({ enabled: import.meta.env.DEV })
```

`enabled: false` 时不插入 DOM、不补丁全局函数；只是模块仍会被打包。对体积敏感的项目用动态导入。

## 6. SSR / Nuxt / Next

- `createDevtools()` 本身可在 Node 中执行（只创建对象，不碰 DOM）。
- `mount()` 在 `typeof document === 'undefined'` 时直接返回。
- Vue 插件在 `document.readyState === 'loading'` 时延迟到 `DOMContentLoaded`。
- Nuxt 只在客户端 plugin 中调用：`plugins/devtools.client.ts`。

## 7. 调试与自动化

- `exposeGlobal: true` 会挂到 `window.__RINOVA_DEVTOOLS__`，可在控制台执行：
  `__RINOVA_DEVTOOLS__.open('network')`、`.setValue('gateway', '...')`。
- 自定义全局名：`exposeGlobal: 'MY_TOOLS'`。
- Shadow DOM 是 `open` 模式，Playwright / CDP 可穿透：

```ts
const host = page.locator('rinova-devtools')
await host.locator('.rdt-launcher').click()
await host.locator('[data-plugin="network"]').click()
```

## 8. 多实例？

不要。网络与日志通过全局补丁实现，多实例会重复包装、`destroy()` 只还原一层。需要多个入口时共享同一个实例：

```ts
export const devtools = createDevtools(options)
```

## 9. 接入检查清单

- [ ] `storagePrefix` 改成项目专属，避免同域串配置
- [ ] `enabled` 绑定环境，生产关闭
- [ ] 配置的 `key` 与业务读取处一一对应，避免拼写漂移
- [ ] `token` 一类敏感字段用 `copyable` 只读，不做可编辑 input
- [ ] 真机 / 窄屏确认面板不遮挡关键操作（窄屏为全屏抽屉）
- [ ] 自定义插件在 `onDispose` 里清理定时器与子应用
