# 02 架构设计

## 1. 分层

```
┌──────────────────────────────────────────────┐
│ 宿主应用（Vue / React / Svelte / 原生）        │
│   └─ 适配器（可选，仅生命周期 + 响应式桥接）    │
├──────────────────────────────────────────────┤
│ @rinova/devtools                             │
│   createDevtools(options)                    │
│   ├─ Runtime（config / network / logs / bus） │
│   ├─ Shell（shadow DOM：悬浮球 + 面板骨架）    │
│   └─ Plugins                                 │
│        ├─ 内置：config network storage …      │
│        └─ 业务：render(container, ctx)        │
└──────────────────────────────────────────────┘
```

三条硬约束：

1. **内核不 import Vue / React**，`package.json` 里没有框架依赖。
2. **UI 全部在 Shadow DOM 内**，宿主 CSS（reset、Tailwind preflight、组件库）无法污染，反之亦然。
3. **插件只拿到 DOM 容器与上下文**，不接触内核私有状态。

## 2. 目录

```
packages/core/src
├─ create-devtools.ts      # 公共 API、实例生命周期、全局快捷键/采集开关
├─ types.ts                # 全部对外类型（无框架依赖）
├─ core/
│  ├─ runtime.ts           # 插件与内核之间的窄接口
│  ├─ config-store.ts      # schema → values，持久化与事件
│  ├─ network-capture.ts   # fetch / XHR 补丁
│  ├─ console-capture.ts   # console / 未捕获异常
│  ├─ emitter.ts           # 事件总线
│  └─ storage.ts           # 命名空间存储、剪贴板、下载
├─ ui/
│  ├─ shell.ts             # 悬浮球、面板、侧栏、resize、拖拽、快捷键
│  └─ dom.ts               # h / icon / button 等 DOM 工具
├─ plugins/                # 内置面板（与第三方插件同构）

└─ utils/                  # 纯函数：格式化、cURL、快捷键
```

## 3. 挂载流程

```ts
const devtools = createDevtools(options)
devtools.mount()
```

1. 创建 `<rinova-devtools>` 宿主元素，`position: fixed; inset: 0; pointer-events: none`，插入 `document.body`。
2. `attachShadow({ mode: 'open' })`，注入一份编译后的 CSS 字符串（Vite `?inline`）。
3. 启动网络 / 日志采集（可在 options 关闭）。采集在面板打开前就开始，保证首屏请求不丢。
4. 按顺序创建插件：内置 → 第三方（同 id 覆盖内置）。
5. 每个插件拿到一个独立容器，**首次注册即渲染并常驻**，切换面板只切 `display`，不丢滚动位置和订阅。
6. 恢复界面偏好（主题 / 停靠 / 宽度 / 上次面板 / 悬浮球坐标）。

`destroy()` 反向执行：注销插件监听、还原 `fetch` / `console`、移除宿主、清理全局引用。

## 4. 为什么用 Shadow DOM

- 调试工具必须"贴脸可用"，但不能被宿主的 `button { ... }`、`* { box-sizing }`、tailwind reset 改坏。
- 宿主也不能被我们污染：所有选择器都在 shadow root 内，唯一暴露的是宿主元素本身（inline style + `data-rinova-devtools`）。
- 主题通过 `:host` 内的 CSS 变量切换，不依赖任何全局 class。

代价与对策：

| 代价 | 对策 |
| --- | --- |
| 弹层不能超出 shadow root | 面板本身就是 fixed 定位的独立层，不需要 Teleport |
| 字体不继承宿主 | 显式声明系统字体栈，中文优先 PingFang / 微软雅黑 |
| 截图/自动化工具需穿透 shadow | 开放 `mode: 'open'`，文档给出 CDP / Playwright 选择器示例 |
| 浏览器原生 datalist 在 shadow 内支持不一 | `allowCustom` 字段使用自绘下拉菜单，不依赖 datalist |

## 5. 事件模型

内核使用极小的 `Emitter`，不依赖任何响应式库。事件名是稳定契约：

| 事件 | 载荷 | 触发时机 |
| --- | --- | --- |
| `mount` / `destroy` | `undefined` | 挂载 / 销毁 |
| `open` / `close` | `{ plugin }` / `undefined` | 面板开关 |
| `config:change` | `{ values, changed, source }` | 配置值变化（`source: user/program/reset`） |
| `config:fields` | `ConfigField[]` | 动态注册字段 |
| `plugin:activate` | `{ id }` | 切换面板（供插件做懒刷新） |
| `network:change` / `log:change` | — | 采集器状态变化（壳层刷新角标） |
| `actions:change` | `DevtoolsAction[]` | 快捷操作增删 |
| `ui:theme` / `ui:dock` / `ui:width` / `ui:reset` | 对应值 | 设置面板修改外观 |

业务侧最常用的是 `config:change`；Vue 适配器就是把它翻译成 `shallowRef`。

## 6. 状态归属

| 状态 | 存储位置 | 生命周期 |
| --- | --- | --- |
| 配置值 | `localStorage: <prefix>:values` | 跨刷新 |
| 界面偏好 | `localStorage: <prefix>:ui` | 跨刷新 |
| 插件私有状态 | `localStorage: <prefix>:plugin:<id>:*` | 跨刷新，由插件决定 |
| 网络记录 / 日志 | 内存环形缓冲（200 / 300 条） | 刷新即清空 |
| 当前打开的面板 | 内存 + `ui.activePlugin` | 刷新后恢复面板，但不自动打开 |

## 7. 单实例约束

网络采集通过补丁全局 `fetch` / `XMLHttpRequest` 实现。**同一页面只应创建一个实例**；重复 `mount()` 是幂等的，重复 `createDevtools().mount()` 会套娃补丁（`stop()` 只能还原一层）。需要多入口时复用同一实例（如 `app.use` + 全局变量）。

## 8. 构建与体积

- `vite build`（lib 模式，ESM）+ `tsc --emitDeclarationOnly`。
- 样式：Less → `?inline` → 打进 JS 字符串，使用方无需安装 Less，也不会有额外 CSS 请求。
- 图标：从 `lucide` 具名导入并按名称建表，只有用到的图标进入产物。
- 当前产物：`dist/index.js` 约 112KB（gzip 30.5KB），无运行时依赖。

## 9. 兼容性

- 目标 ES2020，浏览器需支持 Shadow DOM、`color-mix()`、`pointer` 事件。
- Chrome / Edge 100+、Safari 16.4+、Firefox 113+。
- SSR：`createDevtools()` 可在 Node 中调用（不触碰 DOM），`mount()` 在无 `document` 时直接返回。
