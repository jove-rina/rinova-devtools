## 二、今天的判断性结论

| 问题 | 结论 |
| --- | --- |
| 参考实现的径向菜单要不要照搬 | 不照搬。改成"悬浮球 + 侧栏 + 停靠面板"，信息密度、键盘操作、窄屏可用性都更好；径向菜单留到 v0.3 再评估 |
| 快捷登录账号管理要不要内置 | 不内置。它绑死工号/登录协议/后端接口，放入插件或 action，公共包只保留通用能力 |
| 配置值优先级 | 本地保存值覆盖代码默认值，避免发版重置用户调好的环境；需要重置时用"恢复默认" |

| 现在能否接入真实项目 | Vue 3 + Vite 项目可试点；两个前置项：分发方式、token 等敏感字段不能进 localStorage |
| 生产包怎么隔离 | 动态 import + `enabled` 双保险；已用脚本验证产物 57 bytes，不靠口头承诺 |
| 底部停靠高度不持久 | 接受。v0.1 只持久化宽度，高度每次恢复默认，不在小版本里加状态 |

## 三、踩坑记录

1. **悬浮球点不动**：宿主动了 `pointer-events: none`，所有子元素继承为 none；程序化 `.click()` 正常，真实鼠标无效。→ 交互元素显式 `pointer-events: auto`，实机用 `Input.dispatchMouseEvent` 验证。
2. **网络面板让慢接口更慢**：补丁里 `await response.clone().text()` 读完才返回 Response。→ 先返回 Response，clone 体异步读取后补写条目。
3. **cURL 引号时有时无**：`SHELL_UNSAFE` 带 `/g`，`.test()` 的 `lastIndex` 在多次调用间累加。→ 去掉 `g`。
4. **快捷键单测在 mock 环境失败**：`KeyboardEvent` 的修饰键为 `undefined`，与 `false` 严格比较不相等。→ 统一 `Boolean(event.altKey) === hotkey.alt`。
5. **危险动作第一次点击就执行**：执行按钮的 click 冒泡到卡片，两个 handler 连续触发；第二次进入确认态时又被冒泡执行。→ 执行按钮 `stopPropagation`。
6. **console 无法还原原函数**：`stop()` 写回的是 `bind(console)` 后的新函数，引用不相等。→ 保存原函数，包装里用 `apply(console, args)`。
7. **localStorage 配额满后读不到刚写的内存副本**：`get` 只查 localStorage。→ 读不到时回退到内存。
8. **空面板没有提示**：`builtinPlugins: false` 且未注册插件时，打开只有空白。→ 增加空态，首个插件注册后自动激活。
9. **浏览器自动化测不到真实拖拽**：后台标签页 CSS transition 冻结，`getBoundingClientRect` 可能是关闭态坐标；`location.reload()` 在当前 harness 里会变 `about:blank`。→ 测量前 `Page.bringToFront` + 等待，或模拟 reduced-motion；刷新改用 `goto` 到同一 URL。
10. **工作日志进不了提交**：`.gitignore` 的 `logs` 通配把 `docs/logs/` 也忽略了（`git status` 里根本不出现）。→ 改成 `/logs` 只忽略根目录，`git check-ignore` 确认后重新 add。
