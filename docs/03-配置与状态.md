# 03 配置与状态

配置面板不是"表单"，而是**接入方用 schema 描述的一组运行时常量**。它解决的是：本地 / 测试 / 灰度 / Mock 之间切换时，不想改 `.env` 再重启。

## 1. 字段 schema

```ts
interface DevtoolsOptions {
  groups?: ConfigGroup[]   // 分组顺序与说明
  config?: ConfigField[]   // 字段定义
  values?: ValueMap        // 代码侧初始值（低于本地保存值）
}
```

### 字段类型

| type | 必要属性 | 产出类型 | 说明 |
| --- | --- | --- | --- |
| `select` | `options` | `string` | 固定下拉；`allowCustom: true` 时渲染为可自由输入的组合框，右侧按钮展开预设 |
| `text` | — | `string` | `copyable: true` 时只读并提供复制按钮；`mono` 使用等宽字体 |
| `textarea` | — | `string` | 多行文本，适合长 token / JSON |
| `number` | — | `number` | `min / max / step` |
| `switch` | — | `boolean` | 行式布局，描述在左、开关在右 |

公共属性：`key`、`label`、`group`、`description`、`disabled`、`defaultValue`。

```ts
createDevtools({
  groups: [
    { id: 'iface', label: '接口', description: '网关与灰度' },
    { id: 'debug', label: '调试开关' }
  ],
  config: [
    {
      key: 'gateway',
      type: 'select',
      label: '网关',
      group: 'iface',
      allowCustom: true,
      options: [
        { label: '本地', value: 'http://localhost:8081', description: 'vite' },
        { label: '测试', value: 'https://test.example.com' }
      ],
      defaultValue: 'http://localhost:8081'
    },
    {
      key: 'token',
      type: 'text',
      label: 'TOKEN',
      group: 'iface',
      copyable: true,
      mono: true
    },
    { key: 'abDebug', type: 'switch', label: 'AB 调试', group: 'debug' }
  ]
})
```

## 2. 取值优先级

```
localStorage 已保存值  >  options.values / defaultValue  >  类型零值
```

- 用户改过一次之后，代码里再改默认值不会覆盖他的本地值；设置面板的"恢复默认"或 `resetConfig()` 可清除。
- 新增字段时优先读取本地历史值（即使该字段是在挂载后通过 `registerConfigField` 动态注册的）。
- 删除字段后，其历史值会在下次持久化时被丢弃。

## 3. 业务侧读取

```ts
// 非响应式（事件回调、请求拦截器）
const gateway = devtools.getValue('gateway', '')
```

Vue：

```ts
const { values } = useDevtools()
console.log(values.value.gateway)
```

React / Svelte：监听 `config:change` 后写入自己的 store（见 05）。

## 4. 写入与事件

```ts
devtools.setValue('gateway', 'https://gray.example.com') // source = program
devtools.setValues({ abDebug: true, ueDebug: false })
devtools.on('config:change', ({ values, changed, source }) => {
  if (changed === 'gateway') rebuildHttpClient(values.gateway)
})
```

`source` 用于区分：

- `user`：用户在配置面板修改
- `program`：代码 `setValue/setValues`
- `reset`：恢复默认

事件同步派发；持久化在派发前完成，监听器里读 `getValues()` 一定拿到新值。

## 5. 持久化键

| 键 | 内容 |
| --- | --- |
| `<prefix>:values` | 所有配置值（JSON） |
| `<prefix>:ui` | 主题、停靠、宽度、上次面板、悬浮球坐标 |
| `<prefix>:plugin:<id>:<key>` | 插件私有状态 |

`prefix` 默认 `rinova-devtools`。**不同项目共用同域时务必改 prefix**，否则会串配置。

## 6. 网络 / 日志的保留策略

- 网络：内存环形缓冲，默认 200 条，`network.maxEntries` 可调；单条响应体上限 200KB，超出截断并标注。
- 日志：内存环形缓冲，默认 300 条，`maxLogEntries` 可调；同一级别、同一内容在 1.2 秒内重复会合并计数。
- 两者都不落盘，刷新即清空；这是刻意设计，避免把 token、响应体写进 localStorage。

## 7. 运行时开关

```ts
createDevtools({
  enabled: import.meta.env.DEV,
  captureNetwork: true,
  captureConsole: true
})
```

- `enabled: false` 时 `mount()` 直接返回，不插入 DOM、不补丁全局函数；`getValues()` 等纯状态 API 仍可用。
- `enabled` 支持函数，每次 `mount()` / `open()` 时求值，可用于"当前用户是管理员才显示"。
- 关闭网络采集用 `captureNetwork: false` 或运行时 `devtools.network.setCapturing(false)`。

## 8. 主题

`theme: 'dark' | 'light' | 'auto'`，默认深色。`auto` 跟随 `prefers-color-scheme` 并监听变化。用户可在设置面板覆盖，覆盖值持久化。

颜色全部收敛在 `packages/core/src/styles/tokens.less` 的 CSS 变量里；业务不需要、也不应该覆盖内部 class。需要品牌化时优先换 `--rdt-accent`。
